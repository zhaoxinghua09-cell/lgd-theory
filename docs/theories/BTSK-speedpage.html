BTSK 双时态知识库

TH-MED-003 · Bitemporal Knowledge Base · 2026-09-08 · SynomosAI × MedXpert · CC BY 4.0

审计要回答的从来不是"现在知道什么"，而是"当时知道什么"——双时态是知识成为证据的前提。

双时间轴

时间轴回答的问题治理用途
有效时间 Valid time这条知识在现实世界里何时为真？回放决策时刻的世界状态
事务时间 Transaction time我们何时知道/录入/修正了它？审计知识自身的演化，识事后改口

两轴正交：任何知识条目可回答四问——现在有效吗、当时有效吗、何时录入、何时修正。AI 依据知识库作出的每个结论，都可回溯到"决策时刻的知识基线"——这是 LGD-II「有证」证据重建的知识层地基。

落地（MedXpert-RA 知识库）

双机同步（sync_scan / evolve_scan）保持双时态一致；知识条目版本化，修正不改写历史而是追加新版本——"过去的记录永远以过去的样子可查"。

2026 前沿对照（2026-09-08）

Zep Graphiti 将双时态数据模型工程化于 agent 记忆层（valid/transaction 双时间轴，biotemporal knowledge graph）——这是对 BTSK 主张的工程呼应，印证双时态正在成为 agent 记忆的公认需求。BTSK 的差异化贡献不在数据模型本身（关系数据库时代已成熟），而在治理规矩层：双时态作为证据资格条件（无双时态的知识引用不具备审计证据资格）、与 LGD-II 证据工件的绑定规范、以及记忆修改的门禁语义（改知识=过闸，历史可查不可抹）。
