记忆锚点 = AI 身份 · Memory-Anchor Identity Theory (MAIT)

记忆连续 = 身份连续 · 记忆断裂 = 身份须重新认证 · 记忆锚点层是标准组织未认领的空白

一句话定义

AI 持久身份的认定，应锚定在其可验证、不可篡改、可跨会话 / 跨入口携带的记忆之上。现有标准（W3C DID 管"标识"、VC 管"凭证"）解决了"它是谁、有什么证"，却不解决"它的记忆连续吗、历史可溯吗"。一旦记忆被污染、重置或平行分叉，凭证依旧有效，但"身份"已悄然替换——这是监管审计的盲区。

AI 身份五层模型

I = ⟨ Identity, Credential, Capability, Behavior, MemoryAnchor ⟩ ── 标识 Identity → W3C DID ✅ 已认领 ── 凭证 Credential → W3C VC ✅ 已认领 ── 能力 Capability → 运行时态/评测 ✅ 已认领 ── 行为 Behavior → 运行时日志/审计 ✅ 已认领 ── 记忆锚点 MemoryAnchor → ⚠️ 无人认领（MAIT 主张层）

前四层已被标准组织认领；唯"记忆锚点层（Memory-Anchored Layer）"至今无任何标准组织（W3C / ISO / NIST）正式认领。记忆锚点的可携带性、可验证性、连续性构成 AI 身份的第四信用支柱，与 DID/VC 互补而非替代。

形式化判据

  • 身份连续性：continuity(I_t, I_t') ⇔ portable(M) ∧ verifiable(M) ∧ h(M_t)=h(M_t')
  • 降级 / 重认证：若 h(M_t)≠h(M_t')（污染 / 重置 / 分叉），则身份信用降级，须重新走 UBIC"有籍"认证，而非沿用旧凭证。

记忆锚点的指纹 h(M) 与谱系 prov(M) 使"是否仍是同一个 AI"成为可外部验证、可失败注入测试的命题。

我们不主张率先提出 "identity anchors" 一词，而主张以"记忆锚点层空白 + 记忆作根锚 + 可验证可携带实证 + 治理理论链"这一组合构成可独立署名与标准化的贡献。

与 LGD / UBIC / A³ 的理论链

  • LGD 全程治理论：MAIT 是"有籍·有证·有门禁"在 AI 身份维度的实例化。
  • UBIC 人格户籍协议：提供"有籍"登记；MAIT 的 MemoryAnchor 是其可验证、可携带的记忆根。
  • A³ 造 AI 三定律：提供行为边界；MAIT 提供身份根。
  • 真实参照法 (RRM)：人类"户籍+身份证+记忆连续性"映射为 AI 的"DID+VC+记忆锚点"。

标准化路径

以"memory-anchor extension"提案参与 W3C DID 工作组，主张在 DID 文档中增加可验证的 memoryAnchor 字段（指纹 / 谱系 / 跨入口可携带封装）。占位三步：专家（理论文档 + 开源实现）→ 警察（第三方可复现验证）→ 标准（SDO 提案）。

诚实边界

  • MAIT 是理论主张，非规范；对接 W3C 仅是规划。
  • 记忆可携带降低"身份漂移"成本，但无法根除恶意重放，须与 UBIC 凭证、A³ 门禁联合使用。
  • 与 Menon (2026) 诚实关系：其在"内部记忆韧性"上有价值且开源；MAIT 补其"外部可审计身份 + 标准层空白"未覆盖处。
