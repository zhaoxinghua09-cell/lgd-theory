真实世界参照法 · Real-world Reference Method (RRM)

凡自治之物，先问"真实世界里谁在管、怎么管、凭什么可信"，把成熟机制平移为治理骨架

一句话定义

真实世界参照法（RRM）：面对任何一个"自治之物"（AI、智能体、算法化器械、机器人……），不急于从零发明治理规则，而是先问——"真实世界里，谁已经在管类似的东西？它怎么管？凭什么让人信？" 然后把那个已被验证的成熟真实机制作为"参照锚"，平移为治理骨架。

为什么需要 RRM（与 RWS/RWE 的区别）

通用语境下的 RWS/RWE（真实世界研究 / 真实世界证据） 是循证医学的方法论——用真实诊疗数据产生证据。RRM 不是它，而是治理设计的元方法：

动作用真实数据产生证据用真实世界的成熟机制做治理骨架
提问"真实世界里效果如何？""真实世界里谁在管、怎么管、凭什么可信？"
产出真实世界证据可平移的治理框架（如 LGD 三律）

RRM 把"参照真实世界"从证据层面提升到了方法层面：它是一切下游理论（LGD、MAIT、UBIC…）的"方法生成器"。

RRM 工作流

识别自治之物→ 找真实世界母版机制→ 抽象为通用三律/元规则→ 平移到目标域治理骨架→ 用真实机制校验可信度

关键判据

  • 不编造、可溯源：每个治理规则都能指回一个真实世界母版机制，而非凭空设定（对应 EIFP 不编造原教旨）。
  • 可重放、可追责：参照链条可追溯，治理决策可审计。
  • 收敛优于复制：相近领域优先并入已有母版映射，而非另起平行理论。

与 LGD / MAIT 的锚定关系

RRM（元方法 / 第一性原理） ├─ 母版：医械全生命周期监管 → 抽象 → LGD 三律（有籍·有证·有门禁） ├─ 母版：人类身份确认 → 抽象 → 标识+凭证+记忆锚点 → MAIT └─ 母版：户籍/护照 → 抽象 → UBIC 人格户籍协议 即：LGD / MAIT / UBIC 都是 RRM 在不同真实世界母版上的"实例化"。

诚实边界

  • RRM 是方法论主张，不是规范；"参照"是设计启发而非法律结论。
  • 真实世界母版本身也在演进，平移需随母版更新而重新校验。
  • RRM 不替代领域专业知识，而是为领域治理提供可复用的"骨架 + 校验"方法。

2026 前沿对照（2026-09-08）

arXiv 2508.03095（五方案综述）与 arXiv 2604.23280（AI Identity: Standards, Gaps）两篇独立学术文献印证 RRM 的核心判断：现有方案全部是单点/单层（身份、声誉、支付各自为战），"Between those moments（enrollment/access/presentation/creation）无人处理"——全程链条仍是空白。RRM 的元方法（找真实参照→同构映射→先验可疑）正是把单点串成链条的生成器。
