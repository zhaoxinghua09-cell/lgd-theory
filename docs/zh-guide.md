## 一、三律（一句话版）

| 律 | 一句话 | 最常见的误用 |
|---|---|---|
| **有籍**（Registry） | 先登记它是什么、谁的、什么版本，再谈它做了什么 | 先跑起来再补登记 → 出事后无法定位主体 |
| **有证**（Evidence） | 它做过的每一件事都要能被打包、被别人离线复算 | 只留自家日志 → 对方可以说"你改过" |
| **有门禁**（Gates） | 每个越权触点判一次，默认拒绝 | 只在入口审一次 → 长会话中途权限漂移没人管 |

**判定顺序：先籍、再证、后门，顺序不可换。**
理由很朴素：没有登记，就无法确定"这是谁的证据"；没有证据，就无法判断"这道门该不该开"；门放在前两者之前，就变成了拍脑袋。

## 二、五个常见误解

1. **"有籍 = 实名认证"**——不是。有籍要的是**身份 + 能力声明 + 委托关系**，不是自然人身份证。
2. **"有证 = 上链"**——不是。链只是锚定手段之一；核心是**别人能不能离线复算**。
3. **"有门禁 = 内容审核"**——不是。门禁判的是**动作**（调用了什么工具、动了什么数据），不是说了什么话。
4. **"PASS = 可信"**——不是。本生态统一口径是：**观测边界内未检出违规**，不宣称正确、安全或明智。
5. **"三律要一起上才算数"**——恰恰相反：三律是**三个独立可验证的断言**，任一条不成立，就不该宣称整套成立。
