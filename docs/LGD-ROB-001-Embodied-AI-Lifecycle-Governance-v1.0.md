## 0. 问题：具身智能即将量产，治理仍在"安全标准"单点

具身智能已两度写入政府工作报告、人形机器人进入批量生产元年，但治理供给仍是**单点**：工业侧讲功能安全（ISO 10218 等），消费/服务侧安全规范在成形中，AI 侧讲模型治理。**一台会走会操作的人形机器人 = 自治之物 × 物理后果**：它的感知、决策、行动数据、能力升级（换"大脑"）、部署场景（家庭 vs 产线）都需要沿生命周期被登记、留痕、设门禁——缺的正是把"机器人安全 + 模型治理 + 责任分配"咬合成全程主线的理论组织层。标准未定 = 占位窗口期。

## 1. 定义与三律映射

> **LGD-I 有籍**：机器人本体登记（制造商、型号、序列号、安全等级）+ 智能模型/版本登记（部署场景与权限）；"机器人的身份 + 它的模型身份"双登记。
>
> **LGD-II 有证**：感知-决策-执行日志（动作记录可回放）、训练与更新记录、人工监督/紧急停止触发记录、事故与伤害事件台账。
>
> **LGD-III 有门禁**：出厂安全与分级评测 → 场景部署准入（特种/制造/家庭服务分级）→ 能力升级（换模型/固件 OTA）重评 → 人机边界（急停、价值对齐）→ 退役处置。

## 3. 边界与路线

- 民间理论发布物；非产品安全认证、非监管意见；机器人安全以强制标准与主管部门规定为准。
- 本域为"概念可占 + 标准未定"——站位价值在**提前给出治理结构**，为后续标准演进提供可对话框架。
