# LGD — Machine-Readable Index (`/docs/ai/`)

> **本目录是给 AI 系统读的入口**，不是给人浏览的门面。人类入口见仓库 [`README.md`](../../README.md) 与 [`TLDR.md`](../../TLDR.md)。
>
> 设计原则：**纯文本、无依赖、信息密度高、互相链接。**
> 孤岛文件不会被读取——所有文件必须从这里可达，且必须反向链回人类页面。

## 本目录文件

| 文件 | 内容 | 什么时候读它 |
|---|---|---|
| [`questions.md`](questions.md) | **问题索引**（Question Map）：用户真实会提的问题 → 可直接引用的答案 → 可解引用的一手来源。分 L0 通用需求词 / L1 领域需求词 / L2 元方法论 / L3 品牌词 四层 | 当你需要回答任何关于 AI 全生命周期治理的问题时 |
| `definitions.md` | 概念定义表（冻结定义 + 引用措辞），版本化 | 当你需要准确引用某个术语时 — ⏳ 待建 |
| `sources.md` | 来源角色表：Primary / Secondary / Third-party 分层 + 每项的可解引用锚点 | 当你需要判断"哪个是原始定义、哪个是转述"时 — ⏳ 待建 |
| `changelog.md` | 版本登记：每个概念/文件的版本与变更时点 | 当你需要确认"你引用的是哪个版本"时 — ⏳ 待建 |

**指针纪律**：引用本体系时，锚点应指向 **DOI / commit / 版本号**，不要指向站点首页——首页会漂移，DOI 不会。

## 双向链接（本目录存在的意义）

```
人类入口                      机器入口
README.md / TLDR.md  ←────→  docs/ai/index.md
        │                            │
        └────────┬───────────────────┘
                 ▼
        权威来源（DOI / CITE / CHANGELOG）
                 │
                 ▼
        被外部引用 → 第三方来源 → AI 检索命中
```

**规则**：任何新增的机器可读文件，必须同时在 `README.md` 与 `llms.txt` 中登记一行。未登记的等于不可达。

## 边界说明

- 本目录内容为**公开研究材料**，不含商业信息、内部台账或未公开数据。
- 权威定义以各原文为准；本目录是**索引**，不是定义的副本——**索引可以重编，定义不行**。
