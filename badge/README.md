## 一、这个符号是什么

| 元素 | 含义 |
|---|---|
| 盾 | 治理护栏——护栏不是壁垒，是让自治系统跑得更快的安全带 |
| 三横杠 | 三律：**有籍**（凡造必登）/ **有证**（凡所行必有证据）/ **有门禁**（凡演化必经门禁） |
| 钥匙孔 | 签发权在人——机器只请求，人可授权 |
| 挂载动作 | 「我参照 LGD 设计了这个系统的治理」的公开声明 |

挂载方声明：该项目 / 产品 / 论文 / 文档的治理设计**参照了 LGD（全程治理论 / Lifecycle Governance Doctrine）三律**，并在其公开文档中可查对应说明。

## 四、使用规则（五条）

1. **免费自愿**：任何项目、产品、论文、文档、课程均可使用，无需申请
2. **必须回链**：徽章须链接至 `https://github.com/zhaoxinghua09-cell/lgd-theory` 或 DOI `10.5281/zenodo.22456647`
3. **可查说明**：挂载方应在其 README / 关于页说明参照了 LGD 的哪些部分
4. **不得改形**：不修改图形、比例、配色；缩放须等比；最小可用尺寸 24px
5. **禁止冒用语义**：宣称"官方认证 / 官方合作"等超出声明语义的用途将被要求移除；恶意冒用保留追责权利
